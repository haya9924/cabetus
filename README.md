# cabetus

> **出欠の扱い（β）**：前景の出欠詳細は**表示中の1科目だけを読み取る手動プレビュー**で、データベースには保存しません。全科目の取得は、**利用者が時間割の更新ボタンを明示的に押したときだけ**、非公開仮想画面のWebViewでCLASSを巡回し、確認できた科目を専用Roomテーブルへ保存します（物理画面にブラウザ・小窓は出さず、dataSync通知から中止可能。最大10分。時間割に進捗・結果を表示）。認証は手動で、自動ログイン・出席コード入力・出席送信は行いません。実験的な前景の出欠一覧巡回フラグは無効のままです。

> **モバイル出席の読み取り（β）**：ホーム表示中に授業中かつ接続が判明しているときは、最短60秒間隔・1回最大60秒でCLASSのモバイル出席画面を非公開仮想画面から自動で読み取ります。前景でモバイル出席登録を表示中も、RESUMEDかつDOMを検証できた間は自動で読み取ります（登録・送信・出席コード入力は行いません）。受付中などのスナップショットは**プロセス内メモリのみで15分**（日付不一致・検出できた回線種別変化でも失効）。日付・科目・時限を一意に確認できた出席完了（受付時間等からの**保守的な推定を含む**）だけは `mobile_attendance_confirmations` へ永続保存し、手動修正・アプリ記録などより優先します。永続記録は**アプリのデータ消去・アンインストールまで保持**し、読み取り失敗・受付中・メモリ上のキャッシュ消去では削除しません。診断ログは設定で既定オフ、有効時も件数・エラー種別のみで認証情報や画面内容は記録しません。


**東京理科大学の学生生活を1つのアプリに。**

LETUS の課題と CLASS の時間割・出欠をまとめて表示する、理科大生（全学部）向けの非公式 Android アプリです。
神楽坂・葛飾・野田、どのキャンパスでも使えます。

`1.3-beta.3`（β、versionCode 5）。配布版のアプリIDは `org.cabetus` に統一しました。以前の別IDベータ `org.cabetus.beta` のデータは引き継がれません。また、安定版 `1.2` と署名が異なるため、`1.2` がインストール済みの端末には上書きできません。保存データを維持したい場合は安定版をアンインストールせず、別端末などでベータを試してください。

時間割の科目詳細で、年度別に総授業数と目標出席率／必要出席回数を設定できます。
記録済み出欠から欠席可能回数を計算し、残り2回以下（達成不可も含む）は赤表示と警告通知を行います。
割合は必要出席数を切り上げ、遅刻は既存集計に合わせ出席に含めません。休講分は総授業数から除いて入力してください。
未取得の回は検出できないため暫定値です。記録なし・過去の空欄・年度外記録がある場合は計算を保留します。
既存の自動欠席設定で作成された欠席記録も反映されます。誤記録は詳細画面で修正してください。
通知は同年度・同科目の残り2／1／0／達成不可ごとに一度（通知許可が必要）。
アプリ稼働中は記録・設定更新時、画面を閉じた後はWorkManagerの約15分間隔で確認します（OSにより遅延）。
この機能はCLASSからの出欠自動同期を追加するものではなく、実機の表示・通知確認は未完了です。

内蔵ブラウザでは LETUS のファイル選択（システムの選択画面・複数選択）と資料保存に対応しています。
資料は保存確認後にシステムで保存先を選択します（LETUS の HTTPS 同一ホストのみ、上限100MB）。
外部ホストへのリダイレクト、blob/data形式、HTMLの保存は未対応です。
実施中授業の LETUS ボタンは、年度別・ローカル科目コードごとに確認済みの明示マッピング（LETUS コース URL）を最優先します。仮コードの科目は、年度内で一意に確認済みの正式コード（出席対応の official alias）があるときだけそのコードで照合します。明示マッピングが無い場合は、LETUS コース名末尾の括弧書き（科目コード）の完全一致、次に正規化した科目名の完全一致を、一意に決まるときだけ使います（部分一致・大文字小文字無視などのあいまい選択はしません）。授業を特定できないときは LETUS トップへ飛ばさず、LETUS コース対応付けピッカーを開いて明示マッピングを保存できます。
ファイル選択・アップロードおよび保存の実機確認は未完了です。

## ✨ 機能

### 🏠 ホーム
- キャンパス（神楽坂 / 葛飾 / 野田）の**天気予報**
- 時間割から算出した**今実施中・次の授業**（時限・教室つき）
- OpenAI互換APIによる **AI「今日のひとこと」** — 今日の授業と残課題を踏まえたアドバイス
- **残っている課題**を期日順に一覧表示

### 📚 課題
- **LETUS から課題を自動取得**（課題・小テスト・Turnitin ほか）
- 期日順 / 検出順ソート、**科目・提出状況での絞り込み**
- 未提出の期限切れ課題もホーム・課題一覧の既定対象に含め、期限超過だけで非表示にしません。ホームは同じ対象の先頭10件（全件数を併記）。課題タブで追加した絞り込みはホームには適用しません。
- 課題タブに最終更新の試行日時と取得結果を表示（失敗・スキップを成功日時として扱いません）。
- 提出済み・期限切れバッジ、不要な課題の非表示。各課題の非表示ボタンを長押しすると課題単位／コース単位を選択でき、非表示管理から復元可能
- カレンダーボタンで開閉し、並び替え・絞り込みより上に展開する**月カレンダーで期限を確認**（月送り/戻し・今日・6週グリッド・期限件数バッジ・選択日の課題一覧）。対象は一覧と同じ絞り込みで、期限なしの課題は日付に表示しない
- 取得したデータはアプリ内の共有データベースに保存され、ホーム・ウィジェット・通知からも参照

### 🗓 時間割
- 月〜土・1〜7限をスクロールなしで全体表示（長い名前は省略し、タップで詳細）。小画面・大きい文字では全文をセル内に表示できない場合があります。
- 設定の「時間割の配色」で、実効出席率が高いほど緑になる自動配色／科目ごとの手動配色を選択可能。手動色は年度別に保存。率は年度内の終了済み記録に基づき、未記録・実施0回は中立色。未取得の授業回は把握できないため公式の完全な出席率を保証しません。欠席可能あと2回以下の赤警告は両モードで優先。この配色は保存済みの出欠を読むだけで、出欠の自動取得は行いません（取得は時間割の更新ボタンからの明示操作のみ）。新レイアウト・配色の実機確認は未完了です。
- **CLASSの授業変更**：ホーム表示中、ログイン済みのCLASSの「掲示板 → 時間割変更」から休講・実施場所変更などの掲示件名を自動取得し、取得時刻とともに表示します（通常は同じブラウザセッションで15分以上間隔を空け、アプリを閉じた状態では新たに取得を開始しません）。認証切れの場合は「CLASSで確認」からログインしてください。詳細・変更先が件名にない場合はCLASSで確認してください。掲示の詳細は自動で開かず、既読化・時間割の書き換え・出欠判定の変更は行いません。取得内容はアプリの実行中のみ保持します。
- CLASS の学生時間割表を内蔵ブラウザから読み取り、**週間グリッド表示**（今日・現在の時限をハイライト）。PDF取込は廃止し、既存データは維持
- CLASS の学生時間割表をアプリ内ブラウザで開き、**画面内の時間割表と月〜土ヘッダーを確認できた場合だけ自動読取し、科目名・曜日・時限・科目コード・教室をプレビュー確認して保存**（時間割が空のときのみ。既存の時間割がある場合は年度・学期の混在を防ぐため取り込みを中止。科目詳細で `span.jugyoName`・教員・教室・科目コード・単位の並びを確認できた場合だけそのコードで保存し、不明な場合は推測せず仮コード `CLASSWEB-…` を使用。同名で異なる正式コードや、同名の一部でコード欠落がある場合は仮コード統合せず保留。教室が確認できない場合は空欄。同名の正式科目や同じコマの別科目、既存科目と競合するコードは推測せず取り込まない）
- CLASS の出欠詳細をアプリ内ブラウザで開き、**表示中の1科目だけを読み取って内容を確認するプレビュー**（**読み取り専用**）。出欠詳細の読み取り結果はデータベースに保存しません（定期同期・自動開始は行いません）。**全科目の取得は、時間割の更新ボタンから利用者が明示的に開始する背景巡回**で行い、確認できた科目だけを専用Roomテーブルへ保存します。**前景ブラウザ内の出欠一覧自動巡回は実験的で、既定では無効**（開始ボタン・進捗・中止・結果表示を出さず、巡回処理を生成しません）。実施日は年なしの MM/DD 表記のため年を推測せず、画面の 7 桁英数字を正式な科目コードとして扱いません
- CLASS の「モバイル出席登録」画面は**読み取り専用**です（登録・送信・出席コード入力は行いません）。ホーム表示中に授業中かつ接続が判明しているときは、非公開仮想画面から最短60秒間隔・1回最大60秒で自動読み取りします。前景でモバイル出席登録を表示中も、RESUMEDかつ完全一致パスとDOMを検証できた間は自動で読み取ります（明示ボタンは不要）。画面に曜日時限が無いため、**年あり日付から求めた曜日・正規化した科目名の完全一致・出席確認の受付時間と時限の重なりが一意**な場合だけコマを推定し、候補が複数ある場合や受付時間が複数時限に重なる場合は推定せず保留します（直近・先頭の候補を選びません）。受付中などのスナップショットは**プロセス内メモリだけ**で**15分**で失効します（日付不一致・検出できた端末ネットワーク種別変化でも失効。CLASSログアウトや同種回線変更は検出不能）。一方、**日付・科目・時限を一意に確認できた出席完了（受付時間等からの保守的な推定を含む）**は `mobile_attendance_confirmations` へ永続保存し（マイグレーション v5）、出席状況の**最優先根拠**（手動修正・アプリ記録・CLASS・PDFより優先）として扱います。永続記録は**アプリのデータ消去・アンインストールまで保持**し、受付中・読み取り失敗・メモリ上のキャッシュ消去では削除しません。ホームには**「推定」と推定根拠**、読み取り時刻と**古さ**を表示し、古い結果を現在の出席として見せません。学内/学外は**未確認**、実機E2Eは未完了です。全科目の自動巡回（実験的前景フラグ）は引き続き無効です
- 科目タップで教員・教室・単位・出席状況を表示、**公開シラバス**もアプリ内で閲覧

### 📱 ホーム画面ウィジェット
- 残課題の期日一覧をホーム画面に常時表示
- **背景の不透明度（0〜100%）と配色**（Material You ダイナミック / ライト / ダーク / カラー3種）をウィジェットごとに設定可能

### 🔔 通知（すべて個別チャンネル）
- AIによる**今日のまとめ**（時刻指定のデイリー通知）
- **授業開始5分前**のお知らせ — 「出席にカウント」ボタンで出席を記録し、アプリ内ブラウザで CLASS を開く
- **課題の期日**（24時間 / 3時間 / 1時間前）
- **課題の新規検出**：公開日時ではなくアプリが初めて取得した課題を通知。科目・課題名・締切を表示し、複数件は期限順に最大5件＋残り件数を展開表示。提出済み・期限切れ・非表示は新規通知対象外。初回（取得前DBが空）は初回表記の無音通知。単件は課題、まとめは課題一覧へ遷移。定期・手動取得は直列化して二重検出を抑制（実機通知表示は未確認）
- **取得失敗**（要再ログイン時はタップでログイン画面へ）

### ⚙️ 設定
- 自動取得の頻度（毎時 / 毎日+時刻）、**モバイルデータ通信の許可**、見送り回数による強制取得
- ログイン状態の確認・再ログイン、年度の明示設定（2000〜2100）、キャンパス変更。年度変更で既存データの削除・年度別切替は行いません
- テーマ（システム / ライト / ダーク、**Material You** ダイナミックカラー対応）
- AI（OpenAI互換API）のベースURL・APIキー・モデル設定とテスト送信
- 通知の種類ごとのオン/オフ、バージョン表示

### 🚀 初回セットアップ
通知許可 → LETUSログイン（内蔵ブラウザ）→ キャンパス選択 → AI設定 → 完了（X への投稿ボタン付き）を順に案内。AI はスキップ可能です。PDF選択は不要、年度は設定画面で変更します。

## 🔐 しくみ・プライバシー

- LETUSを内蔵ブラウザで閲覧した後、ブラウザを閉じると課題の自動更新を要求します（通信設定を尊重し、実行中の取得は置換しません）。認証切れや通信失敗時は取得成功とは扱いません。
- CLASSのメニュー自動移動・全科目出欠の自動保存は未対応です。時間割の自動読取は対象画面を開いた後のみで、保存は確認が必要です。今回のブラウザ自動読取・新UIの実機確認は未完了です。
- LETUS / CLASS へのログインは**アプリ内の WebView 上で大学の SSO（Shibboleth / Microsoft）に直接**行い、パスワードはアプリに保存しません。取得した Cookie は端末内にのみ保持されます。
- 課題・時間割・出欠などのデータはすべて**端末内のデータベース**に保存されます。外部サーバには送信しません（AI機能を設定した場合のみ、今日の授業・課題の要約があなたが指定したAPIへ送られます）。
- PDF取込は廃止しました（保存済みの記録は保持）。時間割はアプリ内ブラウザの学生時間割表から、表示検証後に画面単位で一度自動的に表示中の科目名・曜日・時限・科目コード・教室を読み取って追加保存できます（Cookie・ストレージ・入力欄・hidden 要素は読み取りません）。科目コードは科目詳細で項目の並びを確認できた場合だけ使用し、不明な場合は推測せず仮コード `CLASSWEB-…` になります。同じ科目名で異なる正式コードが確認できた場合や、同名の一部でコード欠落がある場合は仮コードで統合せず保留します。教室が確認できない場合は空欄にします。CLASS の画面から年度・学期は取得できないため、既存の時間割がある場合は混在防止のため取り込みを中止します。既存の科目・時間割は上書きしません。**出欠詳細は、アプリ内ブラウザで表示中の1科目を読み取って内容を確認するプレビュー専用で、データベースには保存しません**（全科目の自動巡回・定期同期は未対応）。出欠一覧を自動で巡回する機能は**未完成・実機未検証のため既定で無効**で、開始ボタン等の UI を表示せず、巡回処理（`ClassAttendanceTourRunner`）も生成しません（[`ui/browser/ClassAttendanceTourFeature.kt`](app/src/main/java/org/cabetus/ui/browser/ClassAttendanceTourFeature.kt) の `ENABLED = false`。有効化は実機検証後に行います）。単科の出欠プレビューと時間割取り込みは、この無効化の影響を受けず従来どおり利用できます。実施日は実機では年なしの MM/DD 表記のため年を推測せず、画面の 7 桁英数字を正式な科目コードとして扱いません。CLASS をアプリ内ブラウザで開く場合も、パスワードはアプリに保存しません。CLASS の「モバイル出席登録」は、前景で完全一致パスと DOM を確認できた表示中ページを**自動で読み取ります**（読み取りボタンやコード入力は不要）。画面に曜日時限が無いため、年あり日付の曜日・正規化した科目名の完全一致・受付時間と時限の一意な重なりからコマを推定し、一意に決められない場合は反映せず保留します。ホーム用のスナップショットは**プロセス内メモリのみ**で**15分で失効**し、**推定**と**古さ**を表示します。一方、画面の日付と科目・時限を推測なしで一意に確定できた出席完了は、別途確認のうえ `mobile_attendance_confirmations`（マイグレーション v5）へ永続保存し、出席状況の**最優先根拠**（手動修正・アプリ記録・CLASS・PDFより優先）として扱います。受付中・読み取り失敗・キャッシュ消去で確認済みの永続レコードは削除しません。登録・送信・コード入力は行わず、学内/学外は**未確認**、**実機E2Eは未検証**です。

## 🛠 技術スタック

Kotlin / Jetpack Compose / Material 3（Material You）/ Hilt / Room / DataStore / WorkManager / AlarmManager / OkHttp + Jsoup / kotlinx.serialization / Jetpack Glance

- 課題取得ロジックは [waiteu-git/lms-task-watcher](https://github.com/waiteu-git/lms-task-watcher) を参考に移植し、実際の LETUS 認証フロー（Shibboleth → idp.admin.tus.ac.jp → Microsoft ログイン）の計測結果に基づいて調整しています。
- コース列挙は Moodle の AJAX API（sesskey）を第一経路とし、HTML走査にフォールバックします。

## 🔨 ビルド

```bash
export ANDROID_HOME="$HOME/Android/Sdk"
./gradlew :app:assembleDebug        # デバッグAPK
./gradlew :app:testDebugUnitTest    # ユニットテスト
```

- Gradle は JDK 21 が必要です（`gradle.properties` の `org.gradle.java.home` を環境に合わせて変更してください）

cabetus は**非公式**アプリであり、東京理科大学とは一切関係ありません。LETUS・CLASS の仕様変更により動作しなくなる可能性があります。出欠・課題の情報は必ず公式サイトでも確認してください。

> 出欠一覧の自動巡回は**未完成・実機未検証**のため、既定では無効にしています。無効時は巡回の開始 UI・進捗・中止・結果表示を出さず、巡回処理も実行しません。有効化は、一覧の並び・詳細 DOM の切り替わり・「戻る」・中止を実機で確認した後に行います。
>
> CLASS の「モバイル出席登録」は、前景で完全一致パスと DOM を確認できた表示中ページを**自動で読み取ります**（読み取り専用。登録・送信・コード入力は行いません）。画面に曜日時限が無いため、年あり日付の曜日・正規化した科目名の完全一致・受付時間と時限の一意な重なりでコマを推定し、複数候補など一意に決められない場合は保留します。ホーム用のスナップショットは**プロセス内メモリのみ**で**15分で失効**し、**推定**と**古さ**を表示します。日付・科目・時限を推測なしで確定できた出席完了だけは `mobile_attendance_confirmations`（マイグレーション v5）へ永続保存し、手動修正・アプリ記録・CLASS・PDFより優先します。受付中・失敗・消去で確認済みの永続レコードは削除しません。学内/学外は**未確認**、**実機E2Eは未検証**です。全科目の自動巡回は引き続き無効です。
